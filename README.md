# Lazy loading 
   it runs the query requesting data only when needed, which makes the application run more queries, thus slowing the application.

# Eager loading
   it runs the queries witht the main query, which makes the application run less queries, thus making the application slower.

# first version
   it used lazy loading which made it use more queries, so it was slow

# seconn version
   it used Eager loading which made it use more queries, so it was faster
